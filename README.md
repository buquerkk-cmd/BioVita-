# BioVita Dermo — Site Profissional V4

Versão multipágina para GitHub Pages.

## Estrutura
- `index.html` — home editorial
- `produtos.html` — catálogo com filtros
- `produto-*.html` — páginas individuais dos produtos
- `pesquisa.html` — busca por produto, ativo e necessidade
- `diagnostico.html` — diagnóstico interativo
- `kits.html` — kits e preços em HTML
- `sobre.html` — institucional
- `sustentabilidade.html` — responsabilidade ambiental
- `atendimento.html` — FAQ, segurança e atendimento
- `finalizar.html` — ficha de interesse para impressão

## Como publicar
Envie todos os arquivos extraídos para a raiz do repositório GitHub e ative GitHub Pages em `Settings > Pages > Deploy from a branch > main / root`.

## Observação
Projeto educacional. As informações não substituem avaliação dermatológica.
